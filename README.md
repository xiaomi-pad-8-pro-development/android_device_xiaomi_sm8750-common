# Common device tree for Xiaomi SM8750 devices

Shared device tree for Xiaomi Snapdragon 8 Elite (SM8750) devices, used by the
[Xiaomi Pad 8 Pro](https://github.com/xiaomi-pad-8-pro-development/android_device_xiaomi_piano). Android 17, HyperOS 4
`OS4.0.0.44.XPYCNXM` stock files.

Goes in `device/xiaomi/sm8750-common`. See [UPSTREAM.md](UPSTREAM.md) for the
origin of shared parts.
